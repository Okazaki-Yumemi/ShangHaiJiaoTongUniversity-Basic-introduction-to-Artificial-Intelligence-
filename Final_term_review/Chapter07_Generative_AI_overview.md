# Chapter07 生成模型概率


## 1. 生成式AI在做什么?
```
聊天助手
文本生成图像
文本生成视频
编程智能体
蛋白质结构生成
天气、海洋、气旋等科学问题
```

共同点
```
一个输入可以产生多个输出
一些输出比其他输出更好
训练数据种不包含唯一确切答案
输出形式更复杂，信息量更大、更高维
```

## 2. 判别式模型 vs 生成式模型

### 2.1 判别式模型
判别式模型学习的是
```
样本 x-> 标签 y
```

例如
```
给一张狗的图片 -》 这是一只狗
```
w
### 2.2 生成式模型
生成式模型学习的是
```
表情y / 条件信息 -> 样本 x
```

例如
```
输入"这是一只狗" -》 输出一张狗的图片
```

给定条件y，样本x应该长成什么样子

## 3. 生成建模 = 概率建模

```
真实数据有一个数据分布 pdata(x)
模型要学习一个概率分布 p0(x)
训练目标是让 p0(x) 尽可能接近 pdata(x)
```

生成式模型不是简单记住图片，而是在学习
```
什么样的数据更像真实数据
```


## 4.  隐变量模型 z->x
生成式模型通常引入一个隐变量z，来帮助建模数据分布
```
z -> Generator -> x
```
| 符号        | 含义                     |
| --------- | ---------------------- |
| z         | 隐变量，控制姿态、颜色、大小、品种等潜在因素 |
| x         | 可观测变量，例如图像、视频、音频       |
| Generator | 生成器，把隐变量转成样本           |

可以通俗的理解为
```
z 是 草稿、是潜在的特征
x 是 最终生成的结果
```
例如
```
z = "一只小狗，黑色，坐着"
x = "一张小狗的图片"
```
## 5. AE 自编码器
### 5.1 AE 做什么
AE 即 AutoEncoder，自编码器，是一种生成式模型，主要用于学习数据的低维表示和重建数据。
```
输入 x -> Encoder -> 隐变量 z -> Decoder -> 重建 x'
```
类比为
> 先提炼出要点、再根据要点重建出原始数据
训练目标
> 让重建的 x' 尽可能接近原始输入 x
损失函数通常是重建损失
> L = ||x - x'||

### 5.2 AE 的局限性
```
AE 更像死记硬背
隐空间像散落的孤岛
没有见过的中间区域很难预测得到
生成图像模糊
```

## 6. VAE 变分自编码器
### 6.1 VAE 相比于 AE 改变了什么?
AE是
```
x -> 一个确定的Z
```

VAE是
```
x -> 一个分布 q(z|x)
```

### 6.2 VAE的核心公式直觉
PPT的第二十九页给了VAE的训练目标
```
VAE loss = 重建损失 + 正则化损失
```
| 损失    | 作用                  |
| ----- | ------------------- |
| 重建损失  | 让生成结果 x' 像原图 x      |
| 正则化损失 | 让隐空间分布接近标准正态分布 p(z) |

### 6.3 VAE的局限
```
高斯先验假设过强
重构损失假设输出元素之间相互独立
难以建模高维度复杂分布
实际中常作为模块使用，例如 tokenizer / autoencoder
```
## 7. GAN 生成对抗网络
### 7.1 GAN 的核心思想
GAN,即 Generative Adversarial Network，生成对抗网络，是一种生成式模型，主要用于生成高质量的图像、视频等数据。
```
Generator: 生成器，负责生成样本
Discriminator: 判别器，负责区分生成的样本和真实样本
```

### 7.2 GAN 的交替训练

**回合1，训练D**
```
真实数据 -> D -> 1
生成数据 -> D -> 0
```
**回合2，训练G**
```
G生成假图 -> D 误以为是真图 -> G得到奖励
```

### 7.3 GAN 的局限
```
训练不稳定，容易出现模式崩溃:生成器只学会生成少数几种样本，缺乏多样性
一方太强，另一方无法学习
不收敛: G和D 巴巴博弈
难以评估生成质量
```

## 8. Diffusion Models 扩散模型
### 8.1 Diffusion Models 的核心思想
先学习怎么加沙子，再学习怎么把沙子吹走
```
正向过程: 干净图像逐步加噪，直到变成纯噪声
反向过程: 从纯噪声开始，逐步去噪，最终生成干净图像
```

### 8.2 为什么扩散模型效果好
扩散模型也不是第一步生成整张图，而是多步生成，每一步都更简单，容易建模
```
从早噪声开始
-> 粗略结构
-> 轮廓
-> 细节
-> 最终图像
```

### 8.3 缺点
```
生成速度慢
需要大量计算资源
需要多步去噪
```
## 9. Stable Diffusion 稳定扩散模型
Stable Diffusion 是一种基于扩散模型的生成式模型，主要用于生成高质量的图像。


它不是在大像素空间里面做扩散，而是
```
大图 -> VAE编码 -> 小图 -> 扩散模型生成 -> VAE解码 -> 大图
```

## 10.生成模型概览对比

| 模型               | 核心思想        | 优点           | 缺点            |
| ---------------- | ----------- | ------------ | ------------- |
| AE               | 编码再解码，重建输入  | 简单，适合压缩和表征学习 | 隐空间不连续，生成质量差  |
| VAE              | 学习概率化隐空间    | 隐空间更连续，可采样   | 图像容易模糊，先验假设较强 |
| GAN              | 生成器和判别器对抗训练 | 图像清晰，视觉质量高   | 训练不稳定，模式崩溃    |
| Diffusion        | 加噪再逐步去噪     | 生成质量高，训练较稳定  | 推理慢，计算成本高     |
| Stable Diffusion | 在隐空间中做扩散    | 更高效，适合文生图    | 仍需多步采样，结构较复杂  |
