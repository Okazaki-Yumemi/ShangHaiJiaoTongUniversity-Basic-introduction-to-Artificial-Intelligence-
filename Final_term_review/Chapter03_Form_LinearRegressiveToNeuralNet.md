## 3.线性回归Linear Regression
### 3.1 线性回归要做什么
线性回归的目标是找到一个线性函数，使得输入特征与输出目标之间的关系尽可能接近。

最简单的一种线性回归是
```
y = wx + b
```
where:
| 符号     | 含义            |
| ------ | ------------- |
| x      | 输入特征          |
| y      | 预测输出          |
| w      | 权重，决定 x 的影响程度 |
| b      | 偏置，决定整体平移     |
| wx + b | 模型预测结果        |

### 3.2 从一维到多维
```
y = w1x1 + w2x2 + ... + wnxn + b
```

## 4.损失函数: MSE
### 4.1 为什么需要损失函数
模型给出的预测值和真实值之间的差距需要一个量化的指标来衡量，这就是损失函数。

对于线性回归，一般用均方误差MSE
```
MSE = 所有样本的预测误差平方的平均值

L = (1/N) * Σ(y_i - ŷ_i)^2

若模型是  f(x_i) = wx_i + b，则 MSE 可以写成：
L = (1/N) * Σ(y_i - (wx_i + b))^2
```

### 4.2 为什么要平方

1. **消除正负抵消**：如果直接使用误差的平均值，正负误差可能会相互抵消，导致损失函数无法正确反映模型的性能。平方可以确保所有误差都是正数，从而避免抵消问题。
2. **加大大误差的影响**：平方会放大较大的误差，使得模型在训练过程中更关注那些预测错误较大的样本，从而提高模型的整体性能。
3. **数学上的便利**：平方函数是连续且可微的，这使得在优化过程中使用梯度下降等方法更为方便。

### 4.3 最佳模型
最佳映射 f 让损失最小

也就是说， f* = argmin L(f)

## 5.梯度下降
### 5.1 为什么需要梯度下降
我们刚刚已经说过了，我们的目标是让误差最小，那么梯度下降就是找到最小误差的路径。

参数沿着导数，也就是梯度的反方向更新

```
w_new = w_old - α × ∂L/∂w
b_new = b_old - α × ∂L/∂b
```
其中
| 符号    | 含义           |
| ----- | ------------ |
| α     | 学习率          |
| ∂L/∂w | 损失函数对 w 的偏导数 |
| ∂L/∂b | 损失函数对 b 的偏导数 |

### 5.2 为什么是负梯度方向
梯度指向函数上升最快的方向，因此我们需要沿着负梯度的方向更新参数，以确保损失函数的值逐渐减小，从而找到最优解。

### 5.3 学习率
学习率控制每次参数更新的步长. 

**学习率太小**
```
更新缓慢，训练时间长，可能陷入局部最小值。
```
**学习率太大**
```
更新过大，可能导致损失函数震荡甚至发散。
```

## 6.线性回归中的凹函数和局部最优
```
MSE 是凸函数，不用担心陷入局部最优
```

对于线性回归 + MSE 损失的组合，损失函数关于参数通常是一个凸优化问题，它的损失面像是一个碗，只有一个全局最优。

但是神经网络就不一样了，有多层变换、非线性激活函数，损失面可能非常复杂，存在多个局部最优点。

## 7.过拟合Overfitting
### 7.1 什么是过拟合
随着函数阶数的上升，模型会越来越贴近训练集，但是测试误差却会越来越大，这就是过拟合。

可以简单的理解为
```
模型把训练数据的噪声也学进去了
```

### 7.2 为什么训练集表现好还不够
数据需要迁移，模型的能力测试必须得落实到外界。

### 10.1 为什么要加层

## 11.激活函数
### 11.1 激活函数做什么
将输入信号的总和转换成输出信号的函数，称为激活函数。它引入了非线性，使得神经网络能够学习和表示复杂的函数关系。

神经元的基本结构是
```
z = wᵀx + b
a = σ(z)
```
where:
| 符号 | 含义        |
| -- | --------- |
| z  | 净输入，线性加权和 |
| σ  | 激活函数      |
| a  | 激活后的输出    |


### 11.2 为什么必须使用非线性激活函数
如果没有非线性激活函数，无论网络有多少层，输出都只是输入的线性组合，无法学习和表示复杂的非线性关系。

## 12. Sigmoid函数
### 12.1 Sigmoid函数的定义
Sigmoid函数的定义是
```
σ(z) = 1 / (1 + exp(-z))
```
输出范围在0和1之间，可以理解为概率。

### 12.2 导数
Sigmoid函数的导数可以表示为
```
σ'(z) = σ(z) * (1 - σ(z))
```
但是sigmoid函数有一个问题，当 z 的绝对值较大时，sigmoid函数的输出接近于0或1，这时导数接近于0，导致梯度消失问题。

## 13. ReLU 和 Leaky ReLU

### 13.1 ReLU函数
ReLU（Rectified Linear Unit）函数的定义是
```
σ(z) = max(0, z)
```
ReLU函数在正数区域的导数为1，在负数区域的导数为0。

### 13.2 Leaky ReLU函数
Leaky ReLU函数是ReLU函数的改进版本，它在负数区域有一个小的斜率，定义为
```
σ(z) = max(αz, z)
```
其中α是一个很小的正数，通常取0.01。

### 13.3 简单的比较
| 激活函数       | 输出范围        | 优点           | 缺点          | 常见用途    |
| ---------- | ----------- | ------------ | ----------- | ------- |
| Step       | 0 或 1       | 简单           | 不连续、不可导     | 感知机历史模型 |
| Sigmoid    | (0, 1)      | 可解释为概率       | 容易梯度消失      | 二分类输出层  |
| ReLU       | [0, +∞)     | 快、缓解梯度消失     | Dead ReLU   | 隐藏层常用   |
| Leaky ReLU | (-∞, +∞) 分段 | 缓解 Dead ReLU | 不一定总优于 ReLU | 隐藏层备选   |

## 14.神经网络结构
### 14.1 输入层

## 17.Softmax 与 多分类
### 17.1 Softmax函数

多分类的时候模型通常输出多个分数
```
z1, z2, ..., zk
```
这些分数叫做logits, 它们不一定在 0 和 1 之间，也不一定加起来等于 1。

### 17.2 Softmax公式
Softmax函数将logits转换为概率分布，定义为
```
σ(z_i) = exp(z_i) / Σ(exp(z_j)) for j=1 to k
```
例子
```
logits = [2.0, 1.0, 0.1]
softmax(logits) = [0.659, 0.242, 0.099]
```
## 18.One-Hot 与交叉熵 Cross-Entropy
### 18.1 One-Hot编码
如果有三类: 猫、狗、鸟

| 类别 | One-Hot编码 |
| -- | --------- |
| 猫  | [1, 0, 0] |
| 狗  | [0, 1, 0] |
| 鸟  | [0, 0, 1] |

这就是One-Hot编码

### 18.2 交叉熵损失函数
交叉熵损失函数用于衡量两个概率分布之间的差异，定义为
```
L = -Σ(y_i * log(ŷ_i)) for i=1 to k
```
例如，如果真实标签为
```
y = [0, 1, 0]  # 狗
```
模型预测
```
ŷ = [0.659, 0.242, 0.099]
```
那么交叉熵就比较大。如果模型预测
```
ŷ = [0.1, 0.8, 0.1]
```
交叉熵就比较小。

## 19 反向传播
### 19.1 反向传播解决什么问题
```
根据前向传播算出来的预测值和真实值的误差，计算每个参数对误差的贡献程度（梯度），并沿着梯度的反方向更新参数。
```

### 19.2 反向传播为什么需要链式法则
神经网络是一个复合函数，如果想知道某个早期层的参数对最终输出误差的影响，需要通过链式法则将误差从输出层逐层传递回去，计算每个参数的梯度。

### 19.3 反向传播的训练循环

1. 初始化参数
2. 前向传播计算预测值
3. 计算损失
4. 反向传播计算梯度
5. 利用梯度下降更新参数
6. 重复以上步骤直到收敛

```py
optimizer.zero_grad()   # 清空之前的梯度
y_pred = model(x)     # 前向传播
loss = loss_fn(y_pred, y)  # 计算损失
loss.backward()       # 反向传播计算梯度
optimizer.step()      # 更新参数
```

## 20. Batch Batch Size Iteration Epoch
- Batch: 一次前向传播和反向传播处理的样本数量
- Batch Size: 每个Batch中样本的数量
- Epoch: 训练过程中完整遍历一次训练集的过程
- Iteration: 训练过程中每处理一个Batch就算一次迭代

### 20.1 例子
训练集有100个样本, batch_size = 5 ， epoch = 80

那么
- 每个epoch有 100/5 = 20 iterations
- 总共迭代 80 * 20 = 1600 次

### 20.2 三种梯度下降

| 方法            | 每次用多少数据 | 优点       | 缺点              |
| ------------- | ------- | -------- | --------------- |
| Batch GD      | 全部训练集   | 梯度稳定     | 计算慢             |
| SGD           | 一个样本    | 快、有随机性   | 梯度噪声大           |
| Mini-Batch GD | 一小批样本   | 平衡速度和稳定性 | 需要选择 batch size |

## 21. 梯度消失和梯度爆炸
### 21.1 梯度消失
```
梯度在反向传播中一层层相乘；
如果每一层的导数都小于 1；
乘很多次后会接近 0。
```
### 21.2 梯度爆炸
```
梯度在反向传播中一层层相乘；
如果每一层因子都大于 1；
乘很多次后会变得非常大。
```
