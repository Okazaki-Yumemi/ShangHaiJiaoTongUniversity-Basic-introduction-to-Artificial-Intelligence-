# Chapter04 卷积神经网络及其实现

## 1.为什么普通MLP不适合图像?
### 1.1 三个问题
1. 参数过多：对于一个 224x224 的图像，输入层就有 50176 个神经元，如果第一层隐藏层有 1000 个神经元，那么权重参数就有 50,176,000 个。
2. 空间结构丢失：MLP 将图像展平为一维向量，丢失了像素之间的空间关系。
3. 缺乏平移不变性：MLP 对输入的微小变化非常敏感，无法有效处理图像中的平移、旋转等变换。

### 1.2 CNN的设计动机
不要让每个神经元都连接到输入的每个像素，而是让它们只连接到局部区域，这样可以减少参数数量，同时保留空间结构。

对应两个关键词
1. 局部连接：每个神经元只连接输入的一小部分区域。
2. 权重共享：同一层的神经元使用相同的权重，这样可以大大减少参数数量。

## 2.CNN输入
普通MLP通常会把图像展开成一维向量。

而CNN则是保留图像的空间结构
```
H x W x C
```
其中 H 是高度，W 是宽度，C 是通道数（例如 RGB 图像的 C=3）。

## 3.卷积层

### 3.1 卷积核 kernel
卷积核是一个小的权重矩阵，通常是 3x3 或 5x5 的大小。它在输入图像上滑动，对每个位置进行点积运算，生成一个特征图。

### 3.2 卷积操作
单通道情况下，卷积操作可以理解为
```
卷积核覆盖图像局部区域
-> 对应位置相乘
-> 全部相加
-> 输出一个数值
```
### 3.3 为什么卷积层能提取特征
每一个卷积核都可以表达一种特定图像特点

如果某个局部区域的像素排列核卷积核权重分布类似，那么卷积结果就会很大，说明这个特征在这个位置被激活了。

eg:
| 卷积核类型 | 检测效果   |
| ----- | ------ |
| 边缘卷积核 | 检测边界   |
| 模糊卷积核 | 平滑图像   |
| 锐化卷积核 | 强化细节   |
| 纹理卷积核 | 检测纹理模式 |

## 4. 多通道卷积
### 4.1 单个卷积核也有深度
对于RGB图像,输入通道数 = 3 , 那么卷积核不只是3x3,而是3x3x3,每个输入通道都有一个对应的权重矩阵。

### 4.2 一个卷积核产生一张特征图
如果输入是
```
28x28x3
```
使用一个
```
3x3x3
```
的卷积核，输出就是一张feature map

卷积核数量 = 输出通道数 = 特征图数量

## 5. Conv2d 参数含义

Pytorch 常见
```py
nn.Conv2d(in_channels, out_channels, kernel_size, stride=1, padding=0)
```
- in_channels: 输入通道数
- out_channels: 输出通道数（卷积核数量）
- kernel_size: 卷积核大小
- stride: 步长
- padding: 填充
- bias: 是否使用偏置项

例如
```py
nn.Conv2d(3,64,kernel_size=3,stride=1,padding=1)
```

含义就是
- 输入是 RGB 图像（3通道）
- 使用64个 3x3 的卷积核
- 输出是 64 张特征图
- padding = 1 保持输入输出尺寸不变（28x28 -> 28x28）

## 6. 卷积层输出尺寸计算
### 6.1 公式
```
输出尺寸 = (输入尺寸 - 卷积核尺寸 + 2 * padding) / stride + 1
```

## 7.卷积层参数量计算
### 7.1 公式
```
参数量 = (kernel_height * kernel_width * in_channels + bias) * out_channels
```

## 8.Stride 步幅
Stride 是卷积核在输入图像上滑动的步长。默认值为1，表示卷积核每次移动一个像素。

### 8.1 Intuition
```
Stride = 1 -> 卷积核每次移动一个像素，输出尺寸较大，特征图更详细。
Stride = 2 -> 卷积核每次移动两个像素，输出尺寸较小，特征图更粗糙。
Stride = 3 -> 卷积核每次移动三个像素，输出尺寸更小，特征图更粗糙。
```

### 8.2 易错点
Stride 影响输出尺寸，但不影响参数量。参数量只取决于卷积核大小、输入通道数和输出通道数。

## 9.Padding 填充
Padding是在边缘补0或者其他值，以控制输出尺寸。常见的有两种方式：
- Valid padding: 不进行填充，输出尺寸会减小。
- Same padding: 填充使得输出尺寸与输入尺寸相同。

### 9.1 Why padding?
```
不使用padding，卷积操作会导致输出尺寸逐渐减小，可能很快就无法继续进行卷积了。
```
因为图像边缘被卷积核覆盖的粗疏会逐渐减少

## 10.感受野 Receptive Field
### 10.1 定义
感受野是指卷积层输出特征图上的一个像素对应输入图像上的区域大小。它表示了该特征图像素能够“看到”的输入图像的范围。

例如
```
第一层 3x3 卷积核，stride=1, padding=1 -> 感受野 = 3x3
第二层 3x3 卷积核，stride=1, padding=1 -> 感受野 = 5x5
第三层 3x3 卷积核，stride=1, padding=1 -> 感受野 = 7x7
```

### 10.2 为什么喜欢堆叠小卷积核
一层7x7卷积参数
```
7 x 7 = 49
```
三层3x3卷积参数
```
3 x 3 + 3 x 3 + 3 x 3 = 27
```
在通道数相同的简化情况下，3x3参数更少，而且中间可以插入Relu等非线性激活函数，增加模型表达能力。

## 11.CBA Convolution + BatchNorm + Activation

CBA 是卷积层的一个常见组合，包含卷积层、批归一化层和激活函数。它的作用是提高模型的训练稳定性和表达能力。

### 11.1 Convolution
卷积层负责提取输入图像的特征。
### 11.2 BatchNorm
对mini-batch的输出的中间特征做标准化，再通过可学习参数γ和β进行线性变换，增强模型的表达能力。
### 11.3 Activation
激活函数引入非线性，使得模型能够学习和表示复杂的函数关系。常用的激活函数有ReLU、Sigmoid、Tanh等。

## 12.Pooling 池化
### 12.1 池化做什么
池化层通过对输入特征图进行下采样，减少特征图的尺寸和参数量，同时保留重要的特征信息。常见的池化方式有最大池化（Max Pooling）和平均池化（Average Pooling）。
例如2x2max pooling
```
1 1
2 3
```
输出是3，因为3是2x2区域内的最大值。

### 12.2 池化的作用
1. 降低空间尺寸，减少计算量和参数量。
2. 减少计算量
3. 减少过拟合
4. 增强一定的平移鲁棒性

## 13.CNN全流程
```
Input Image
→ Conv + BN + ReLU
→ Pooling
→ Conv + BN + ReLU
→ Pooling
→ ...
→ Flatten
→ Fully Connected
→ Softmax / Classification
```
where
| 模块              | 功能        |
| --------------- | --------- |
| Conv            | 提取局部特征    |
| BatchNorm       | 稳定训练      |
| ReLU            | 引入非线性     |
| Pooling         | 降维、压缩     |
| Flatten         | 把特征图展开成向量 |
| Fully Connected | 综合高级特征    |
| Softmax         | 输出多分类概率   |

## 14.CNN VS MLP
| 维度     | MLP            | CNN           |
| ------ | -------------- | ------------- |
| 输入     | 通常 flatten 成向量 | 保留 H×W×C 空间结构 |
| 连接方式   | 全连接            | 局部连接          |
| 参数共享   | 无              | 有             |
| 图像空间信息 | 容易丢失           | 保留            |
| 参数量    | 大              | 较小            |
| 平移鲁棒性  | 弱              | 更强            |
| 适用任务   | 表格、简单特征        | 图像、视频、空间数据    |

## 15. Deeper CNNs

### 15.1 LeNet
LeNet 是最早的卷积神经网络之一，由 Yann LeCun 在 1998 年提出，主要用于手写数字识别。它包含两个卷积层和三个全连接层。
```
Conv
-> Pooling
-> Conv
-> Pooling
-> Flatten
-> Fully Connected
-> Output
```
特点
```
浅层CNN
小图像
少量卷积核
主要用于简单任务
```

### 15.2 AlexNet
AlexNet 是 2012 年由 Alex Krizhevsky 等人提出的卷积神经网络，标志着深度学习在计算机视觉领域的突破。它包含五个卷积层和三个全连接层。
```
Deeper
Wider
使用ReLU激活函数
使用GPU加速训练
适应 ImageNet 大规模图像分类任务
```

### 15.3 VGG
VGG 是 2014 年由 Visual Geometry Group 提出的卷积神经网络，主要特点是使用了非常小的卷积核（3x3）和较深的网络结构。它包含多个卷积层和三个全连接层。

核心思想是Deeper is better，使用更多的卷积层来提取更复杂的特征，同时保持卷积核的小尺寸以减少参数量。

## 16.深层网络的问题
层数增加后，训练变得困难，可能出现梯度消失或梯度爆炸的问题，导致模型无法有效学习。

提高信号质量传播的手段:
```
1. 使用更好的激活函数（如ReLU）
2. 使用批归一化（BatchNorm）
3. 使用残差连接（ResNet）
4. 权重初始化方法（如He初始化）
```

## 17.ResNet

### 17.1 ResNet 解决什么问题?
ResNet 通过引入残差连接（skip connections）解决了深层网络训练困难的问题。残差连接允许梯度直接从后面层传递到前面层，缓解了梯度消失的问题。

### 17.2 残差块公式
普通网络希望子网直接学习
```
y = H(x)
```
而 ResNet 希望子网学习
```
F(x) = H(x) - x
```
于是
```
H(x) = F(x) + x
```
这就是残差连接的核心思想，通过让网络学习残差 F(x)，而不是直接学习 H(x)，使得训练更容易。
### 17.3 为什么残差链接有效?
如果某几层暂时学不到有用的特征，残差连接允许这些层直接输出输入 x，这样网络至少可以保持性能不变，而不是退化到随机猜测。这使得训练更深的网络成为可能。

### 17.4 Basic Block 和 Bottleneck Block
| 结构               | 特点                   | 常见位置                  |
| ---------------- | -------------------- | --------------------- |
| Basic Block      | 2 层，每层通常 3×3 conv    | ResNet-18 / ResNet-34 |
| Bottleneck Block | 3 层，使用 1×1 conv 控制维度 | ResNet-50 / 101 / 152 |

Bottleneck Block 通过使用 1x1 卷积来减少和恢复维度，降低了计算量，使得更深的网络成为可能。

## 18.表征和迁移学习
### 18.1 什么是表征?
深度网络中，越靠前的层学到越低级的视觉特征
```
边缘 -> 纹理 -> 形状 -> 物体
```
越靠后的层学到越高级的语义特征
```
狗的耳朵 -> 狗的脸 -> 整只狗
```
这些中间特征被称为表征（representation），它们是网络对输入数据的抽象理解。

### 18.2 为什么可以迁移
不同任务可能类别不同，但是底层视觉有共性，再大规模数据集上训练好的CNN，前面几层往往可以迁移到新任务上，作为特征提取器使用。

## 19.Pre-training 与 Fine-tuning
### 19.1 Pre-training
在大规模数据集（如 ImageNet）上训练一个 CNN 模型，学习到通用的视觉特征。
特点
```
1. 需要大量数据和计算资源
2. 学到的特征具有较强的泛化能力
3. 参数多
4. 通用特征、训练时间长
```

### 19.2 Fine-Tuning
在预训练模型的基础上，针对特定任务进行微调。通常会冻结前面几层的权重，只训练后面几层或者全连接层，以适应新任务的类别和数据分布。
特点
```
1. 需要较少的数据和计算资源
2. 可以快速适应新任务
3. 参数少
4. 任务特定、训练时间短
```
### 19.3 冻结权重
冻结权重是指在微调过程中不更新某些层的权重参数，通常是前面几层，因为它们学到的特征更通用。这样可以减少过拟合风险，同时加快训练速度。

## 20.四种微调策略
| 数据量 | 任务相似度 | 推荐策略           | 直觉              |
| --- | ----- | -------------- | --------------- |
| 少   | 相似    | 冻结大部分层，只训练分类头  | 预训练特征已经够用       |
| 少   | 不相似   | 冻结底层，重训较高层和分类头 | 底层视觉特征可用，高层语义需改 |
| 多   | 相似    | 微调高层或全模型       | 有数据支持更精细适配      |
| 多   | 不相似   | 全模型微调，甚至从头训练   | 任务差异大，需要重学大量特征  |
