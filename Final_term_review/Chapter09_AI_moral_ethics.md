## 2. 偏见从何而来 RLHF的假设

### 2.1 RLHF是什么
RLHF,即 Reinforcement Learning from Human Feedback , 人类反馈强化学习

简化流程
```
模型生成多个回答
-> 人类标注者比较回答的质量
-> 训练奖励模型来预测人类的偏好
-> 使用奖励模型来优化语言模型的输出
```

### 2.2 RLHF的假设

| 假设 / 推定      | 含义           | 潜在问题                |
| ------------ | ------------ | ------------------- |
| 人类偏好存在       | 人有稳定偏好       | 人的偏好可能矛盾、变化、受语境影响   |
| 偏好可量化        | 偏好能转成分数      | 价值判断未必能完全数字化        |
| 奖励最大化 = 更好行为 | 分数越高行为越好     | 可能出现 reward hacking |
| 最优解存在        | 可以找到最佳策略     | 社会问题常没有唯一最优解        |
| 多用户偏好可聚合     | 多人意见能平均      | 少数群体偏好可能被淹没         |
| 偏好可统一优化      | 一个奖励函数适用所有场景 | 医疗、教育、娱乐等场景价值优先级不同  |

所以RLHF的偏见来源不是单一的 "数据脏" ， 而是包括
```
人类标注者本身的偏见
偏好聚合方式的偏见
基础模型预训练阶段的偏见
基础模型预测训练阶段继承的偏见
奖励模型对复杂价值的过度简化
不同场景使用同一的偏好函数
```

## 3. LLM 的两个典型问题: 谄媚和幻觉

### 3.1 谄媚
```
谄媚 = 过度迎合用户的偏好
```

匹配用户的信念、偏见和偏好是预测人类偏好的强特征执意，甚至可能超过过真实性、逻辑性等特征

### 3.2 幻觉
```
模型幻觉是指AI生成看似合理但是事实错误的内容
原因在于大模型本质上是根据上下文预测文本，而不是直接执行可靠的事实验证或者逻辑计算
在事实、法律、医学、数学等高风险场景中、幻觉可能造成严重后果
```

## 4. 为什么要说AI伦理

```
AI开始参与判断、分配、推荐和控制
它影响的不只是效率，而是人的机会、资源、安全和抉择
```

现实冲击案例包括:
```
AI 招聘歧视女性
算法推荐成瘾
人脸数据误伤
数据泄露隐私
```

## 5.AI 伦理的六个核心讨论
| 议题                 | 核心问题               |
| ------------------ | ------------------ |
| 公平性 Fairness       | 算法是否对所有人一视同仁？      |
| 透明性 Transparency   | 人能否理解 AI 如何做决策？    |
| 隐私性 Privacy        | 数据边界在哪里？           |
| 责任性 Accountability | 出事后谁负责？            |
| 自主性 Autonomy       | 是人控制 AI，还是 AI 控制人？ |
| 长期性 Long-term      | AGI 是否带来长期生存风险？    |

## 6. 公平性和偏见
### 6.1 核心问题
```
Garbage in, garbage out
有偏见的数据 -> 有偏见的模型
```

## 7. 透明性和可解释性
### 7.1 核心问题
```
AI说通过了某个测试、达到了某个标准，但我们不清楚它是怎么做到的
```

例如
```
医疗AI误诊: 无法解释为什么误诊了某个病人
贷款被拒绝: 无法解释为什么拒绝了某个申请
```
## 8. 隐私和数据安全
### 8.1 核心问题
```
免费用app的时候，你也可能成为app的一部分
```

案例
```
Cambridge Analytica 数据泄露
人脸识别进校园
大数据杀熟
Clearview AI 人脸数据泄露
智慧食堂通过消费记录识别贫困生
```

隐私问题的关键不是 `数据能不能带来收益` ，而是
```
是否必要
是否经过同意
是否限定用途
是否最小化收集
是否防止二次推断和滥用
```
