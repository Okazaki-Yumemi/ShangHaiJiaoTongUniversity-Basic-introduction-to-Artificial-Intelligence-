## 机器学习、深度学习的简单介绍

```text
深度学习是机器学习的一个分支，而机器学习又是人工智能的一个分支。机器学习通过算法从数据中学习规律，而深度学习则使用多层神经网络来建模复杂的模式和关系。
```
### 机器学习本质

```text
从文本中寻找一个最优的函数映射关系。
```

### 为什么需要机器学习？
```text
数据量大、规则难以定义、决策要求速度高。
```

### 四类机器学习的范式

#### 监督学习

特点
```text
有输入x
有标准答案y
模型学习 x-> y 的映射关系
```
#### 无监督学习
特点
```text
有输入x
没有标准答案y
模型自己发现数据的结构和规律
```
#### 半监督学习
特点
```text
少量有标签数据 + 大量无标签数据
模型利用有标签数据指导无标签数据的学习
```
#### 强化学习
特点
```text
没有标准答案
通过 奖励/惩罚 学习策略
```
## 深度学习时代的介绍
### DNN 深度神经网络
```text
底层学习简单特征
中间层学习组合特征
高层学抽象语义
```

### CNN 卷积神经网络
例子是图像识别和目标检测

**AlexNet**:
```text
建立深层卷积网络的基本架构
卷积 -> 池化 -> 全连接
```
**ResNet**:
```text
网络越深越难训练
核心是残差连接
```
**YOLO**:
```text
You
Only
Look
Once

只看一次图像、直接预测目标位置和类别
```
### RNN 循环神经网络
```markdown
**Many to One**: 机器翻译、文本分类
- 评论文本 -> 负面/正面
- 句子 -> 情感
- 文本 -> 主题

** Many to Many**: 语言模型、文本生成
- 语音 -> 文本
- 中文 -> 英文
```

### GAN 生成对抗网络
```text
Generator & Discriminator
生成器生成看起来真实的数据、而判别器判断数据是真实的还是生成的
```

# Summary

## 重点：几种模型、框架。

| 模型          | 主要处理对象   | 核心思想                  | 典型任务            |
| ----------- | -------- | --------------------- | --------------- |
| CNN         | 图像、网格数据  | 卷积提取局部特征              | 图像分类、目标检测       |
| RNN         | 序列数据     | 按时间顺序传递状态             | 文本、语音、时间序列      |
| GAN         | 数据生成     | 生成器与判别器对抗训练           | 图像生成、虚拟人、风格迁移   |
| Transformer | 序列与多模态数据 | Self-Attention 建模全局关系 | LLM、翻译、问答、多模态理解 |
| Diffusion   | 生成任务     | 从噪声逐步还原数据             | 图像、视频、音频生成      |
| Agent       | 任务执行     | 模型 + 工具 + 规划 + 反馈     | 自动化工作流、复杂任务编排   |
